# Labelforge

CLI tool to manage and synchronize GitHub repository labels from configuration files.

## Problem

Managing GitHub repository labels manually is repetitive, inconsistent, and error-prone, especially across multiple repositories.

## Solution

Labelforge provides a simple CLI to define labels in a configuration file and automatically synchronize them with GitHub repositories.

## Features

- Initialize label configuration
- Synchronize labels with GitHub repository
- Create, update, and delete labels
- Dry-run mode (planned)

## Tech Stack

- Node.js
- TypeScript
- GitHub REST API (future)

## Project Status

Early development (MVP foundation in progress)
